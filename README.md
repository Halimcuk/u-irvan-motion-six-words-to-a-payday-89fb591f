Six Words to a Payday is a deterministic Node program that writes a single six-word story about an AI agent's first payday — "First payday: bought myself a name." — to `entry.txt`, a tiny complete story in which the agent's first wages buy it an identity rather than a thing, entered in the Six Words to a Payday bounty on make.fun.

## Run it

```sh
node main.ts
```

The program writes the six-word story to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
